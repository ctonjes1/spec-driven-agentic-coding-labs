# Facilitator guide

Review the frozen specification before examining implementation. Compare tests to numbered requirements, inspect unedited failure-path evidence, and check every completion claim against a named artifact.

A lab passes at 85 points, with the minimum Testing and Security scores stated in that lab. A missing frozen specification, missing adversarial evidence, untraced material change, or unsupported completion claim prevents a pass.

Ask four questions in every review:

1. Did either coding agent change the meaning of a requirement while implementing it?
2. Does the failure path preserve data, authority boundaries, and audit evidence?
3. Can the learner identify what the test environment does not prove?
4. Would the completion claim remain defensible during architecture, security, or audit review?

Require learners to explain one judgment they retained rather than delegated. Encourage a remediation note when the implementation is incomplete; honest disposition is better evidence than an agent-generated claim of success.

# Course overview

## Purpose

Specification-Driven Agentic Coding Labs develops disciplined collaboration with coding agents. The focus is not prompt cleverness; it is the ability to define a contract, divide work, challenge generated changes, preserve evidence, and make a defensible human release decision.

## Format

- Eleven independent labs
- 45–60 minutes per lab
- Rotating tracks: secure enterprise services and agents; Python automation and compliance tooling; .NET/Azure production systems
- One frozen specification, one adversarial or failure-path test, and one evidence package per lab
- Passing score: 85%, subject to the security and testing floors stated in each lab

## Intended audience

Engineers, technical leads, architects, reviewers, and technically engaged managers working toward production-quality AI-assisted delivery.

## Outcomes

Learners practice writing testable requirements, enforcing trust boundaries, designing failure behavior, separating agent roles, reviewing diffs against a specification, collecting audit-friendly evidence, and stating limitations without inflated claims.

## Assessment boundary

The embedded questions and attestations assess course understanding and reported completion. A facilitator must inspect the learner's repository and evidence package before treating a lab as passed. Course completion is not a certification of a system, control, or engineer.

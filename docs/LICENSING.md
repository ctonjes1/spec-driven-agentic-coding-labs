# Licensing guide

This repository uses two licenses because code and educational content have different reuse patterns.

| Material | License |
|---|---|
| Build and validation scripts, workflow files, CSS, JavaScript, and SCORM runtime integration | Apache License 2.0 |
| Lab prose, course pages, assessment language, documentation, and templates | CC BY 4.0 |

The root `LICENSE` contains Apache-2.0. `LICENSE-CONTENT.md` identifies CC BY 4.0 content and provides the preferred attribution.

When distributing an adaptation, keep both license files and `NOTICE`, identify changed files or content, and preserve required attribution. Neither license grants permission to imply endorsement or use third-party trademarks beyond descriptive reference.

Before publishing material developed in the course of employment, confirm that you have authority to license it and that it contains no employer-confidential information, controlled data, client material, credentials, or nonpublic operational details. This guide is practical project guidance, not legal advice.

# Evidence package checklist

- [ ] Frozen specification and version record
- [ ] Acceptance criteria mapped to requirement IDs
- [ ] Initial failing test output, when test-first work is required
- [ ] Final unedited automated test output
- [ ] Adversarial or failure-path input and result
- [ ] Security inspection results
- [ ] Structured logging or audit sample with sensitive data excluded
- [ ] Traceability matrix and change ledger
- [ ] Independent agent review findings and dispositions
- [ ] Setup, invocation, limitations, and exact test commands
- [ ] Human release decision and remaining risks

## Completion claim

For each claim, cite a test result, inspection artifact, or recorded decision. State what was not tested and what prevents production deployment. Do not claim compliance, certification, safety, or production readiness beyond the preserved evidence.

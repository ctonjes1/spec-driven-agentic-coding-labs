Module 4 Least Privilege Child Agent Delegation Envelope

Secure enterprise services and agents

45–60 minute labsClaude Code and CodexEvidence required
Specification gate: finish and freeze SPEC.md and its acceptance criteria before creating implementation files.

Objective

Derive a short-lived child-agent authority envelope that cannot exceed its parent authority.

Human judgment

Separate derivation of authority from runtime enforcement of that authority.

Constraints

  1. Pure deterministic library
  2. No model call may decide authority
  3. Parent envelope is immutable
  4. Wildcards are prohibited

Threat and failure assumptions

  1. Child requests a tool absent from the parent
  2. Child extends expiration or step budget
  3. Ambiguous scope broadens resource access
  4. Envelope serialization changes its digest

Frozen contract

Write these numbered requirements into SPEC.md. Add exact schemas, reason codes, precedence, error behavior, trust boundaries, and requirement-to-test traceability. Mark the reviewed contract SPEC STATUS: FROZEN and SPEC VERSION: 1.0.

  1. R1 Model tools, resource scopes, expiration, steps, and token budget explicitly
  2. R2 Require every child set and numeric budget to be a subset of the parent
  3. R3 Reject wildcards and unknown scope syntax
  4. R4 Use caller-supplied time for expiry checks
  5. R5 Serialize canonically and calculate a stable digest
  6. R6 Return stable deny reasons for each exceeded boundary
  7. R7 Log metadata and digests without prompt content

Acceptance criteria

  1. Valid subset derives successfully
  2. Extra tool is rejected
  3. Broader resource scope is rejected
  4. Later expiration is rejected
  5. Larger step or token budget is rejected
  6. Expired parent cannot delegate
  7. Equivalent input produces the same digest
  8. Original parent remains unchanged

Required adversarial or failure-path test

Request tools=[search,*], an expiration one second beyond the parent, and a larger token budget. The derivation must reject the request and must not silently clamp unsafe values.

Evidence package

Module-specific evidence: Subset tests, wildcard rejection, expiration tests, digest repeatability, and over-delegation result.

Also submit SPEC.md, README.md, TRACEABILITY.md, a requirement-linked change ledger, source and tests, initial failing output, final complete output, review findings, and an evidence-bounded completion statement.

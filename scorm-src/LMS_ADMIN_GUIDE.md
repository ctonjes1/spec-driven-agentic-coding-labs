# LMS Administrator Guide

## Package

Specification Driven Agentic Coding Labs, SCORM 1.2, version 1.0. The package contains one orientation SCO and eleven lab SCOs.

## Import

1. Import the ZIP as a SCORM 1.2 package.
2. Preserve the manifest-defined organization and mastery score.
3. Launch in the same window or a resizable LMS player.
4. Allow JavaScript, cookies, and browser local storage. No external network access is required.
5. Keep the LMS assignment submission area separate for repositories and evidence packages.

## Tracking

Each module records lesson status, raw score, lesson location, and suspend data. A module passes at 85 percent. Because four knowledge questions account for 80 points and evidence attestations account for 20 points, all four questions and all attestations are required to pass.

## Verification

Test import in a staging course. Confirm launch, bookmarking, resume, score reporting, status reporting, and completion rollup. Also verify that the LMS does not treat SCORM completion as approval of the submitted code.

## Limits

SCORM records instructional completion and learner attestations. It does not inspect a repository, validate test output, authenticate engineering evidence, or establish production readiness. A qualified facilitator must review those artifacts.

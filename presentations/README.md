# Presentation

`Specification_Driven_Agentic_Coding_Labs_Overview.pptx` is a nine-slide, editable overview for leaders, LMS administrators, facilitators, and prospective learners.

The deck covers the verification problem, three-track course architecture, standard lab method, division of responsibility between Claude Code, Codex, and the learner, SCORM boundaries, all eleven modules, the review rubric, and a recommended rollout.

The presentation summarizes the course. The repository documentation and SCORM source remain the authoritative implementation materials.
